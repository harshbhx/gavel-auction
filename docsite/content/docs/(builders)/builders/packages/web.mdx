`packages/web` is the browser client: React 18, Vite and strict TypeScript. It renders the bidder, <Term id="auctioneer-console">auctioneer console</Term>, public screen, audit and <Term id="replay">replay</Term> views from the wire types in `@gavel/shared`. All money is integer cents. All user text lives in `src/copy`.

It holds no business rules. Whether a bid stands, who wins and what is charged are decided by the <Term id="engine">engine</Term> and the payments <Term id="saga">saga</Term> on the server; the client shows the state it receives and sends commands.

## Responsibilities

- **Routes.** `src/routes.tsx` is the route table (first match wins, catch-all last). Routes that need a stored session token are marked `needsToken`; the audit route needs a reviewer token.
- **Live state.** `src/net` wraps the WebSocket behind a `Transport` interface; `connection.ts` reconnects with backoff and `resync.ts` asks for a fresh snapshot after a gap. `src/store` reduces server messages into room state.
- **Payment approval.** `src/payments` hides PayPal behind `PaymentApprovalPort`; there is a fake adapter and a PayPal <Term id="sandbox">sandbox</Term> adapter (`paypalV6Adapter.ts`).
- **Voice input.** `src/audio` captures the microphone and sends it to the `/audio` socket for the auctioneer console.
- **Design system.** `src/design` holds tokens, themes (including the projector theme), primitives and the sandbox and fake-payments labels.
- **Accessibility.** `src/a11y` holds the announcer and focus helpers.

## Public interfaces

The package is an application, not a library, and exports nothing for other packages. Its seams are internal and are what the tests replace:

- `Transport` (`src/net/transport.ts`): `connect`, `send`, `onMessage`, `onStatus`, `close`. The app never touches a WebSocket directly. A scenario transport and a scripted mode feed the same interface in tests and demos.
- `ControlPort` (same file): the auctioneer commands `open`, `pause`, `resume`, `extend`, `hammer` and `kill('STOP')`, sent over HTTP.
- `PaymentApprovalPort` (`src/payments/port.ts`): approval states `idle`, `preparing`, `awaiting_buyer`, `confirming`, `held`, `cancelled`, `declined`, `error`.
- `src/wire/index.ts`: the single import seam for wire types, re-exported from `@gavel/shared`, so the client and the server cannot drift apart.

| File | What it holds |
| --- | --- |
| `src/config.ts` | Reads the `VITE_*` variables at start. A missing or invalid value stops the app with a `ConfigError` that lists names only. An endpoint must be the secure scheme; the plain scheme is accepted only for a loopback host |
| `src/net/connection.ts` | Reconnect backoff 500, 1000, 2000, 4000, 8000 ms with 20 percent jitter; the offline banner shows after 2 s. `unauthorized`, `forbidden` and `invite_used` end the session; `room_full`, `auction_full`, `room_cap` and `rate_limited` stop reconnecting until the bidder asks again |
| `src/net/resync.ts` | Re-sends the join with the stored token and last seq until a snapshot arrives (retry every 3 s) |
| `src/screens/console/shortcuts.ts` | Confirm queue keys Y, N, J and K; ignored while a field has focus or a modifier is held |
| `src/copy/banned.ts` | Wording rules: before the CAPTURED state no catalog string may say charged, pay, paid, payment, capture, debit, billed, deducted or fee (a negation such as "not charged" is allowed) |
| `vite.config.ts` | The sandbox guard and the Content-Security-Policy generator |
| `scripts/check-size.mjs` | The initial-route size gate |

## Invariants

- **Sandbox only.** The Vite plugin `gavel-sandbox-guard` fails a production build unless `VITE_SANDBOX` is exactly `true`, and refuses `VITE_PAYMENTS=fake` without `VITE_ALLOW_FAKE=true`.
- **A fixed Content-Security-Policy.** `buildCsp` generates the policy from the same config: scripts only from self and the PayPal sandbox, `connect-src` limited to self, the configured API and WS origins and the two PayPal sandbox origins, no objects, no inline script allowance.
- **A small first load.** `check-size.mjs` fails the build when the gzip size of the initial route is over 180 KB, or when the PayPal SDK loader, the QR encoder or the replay player is part of that initial graph. The replay screen is loaded lazily.
- **No secret in the bundle.** The root check `npm run check:secrets` builds the web app with canary values and scans the output (see [Infra](/docs/builders/packages/infra)).
- **One wire source.** Wire types come only through `src/wire`, which re-exports `@gavel/shared`. The web source imports `@gavel/shared`; the dependency rule would also allow `@gavel/voice`, but no web source file imports it today.
- **Honest wording.** The banned-wording rules above are applied to the copy catalog by `test/unit/copy.test.ts`.
