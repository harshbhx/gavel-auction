## What each top-level folder is

| Folder | Contents | Owner area |
| --- | --- | --- |
| `packages/shared` | Money in integer cents, ids, errors, events, the wire types and codecs, the replay bundle format | RT |
| `packages/engine` | The pure auction core: commands, rules, the hash-chained <Term id="ledger">ledger</Term>, projections, replay | ENG |
| `packages/payments` | <Term id="hold">Holds</Term>, the <Term id="saga">settlement saga</Term>, webhook verification, the <Term id="fake-paypal">fake PayPal</Term>, the gate scripts under `gates/` | PAY |
| `packages/voice` | Audio framing, speech-to-text clients, the parser, the decision step, evaluation tooling, fixtures | VOI |
| `packages/server` | The single-process host: HTTP routes, the room runtime, WebSocket gateways, stores, boot and config | RT |
| `packages/web` | The browser client | WEB |
| `packages/e2e` | Scenarios, runners, property and load tests, browser and sandbox specs | QA |
| `.github` | Workflows, the shared setup action, issue and pull request templates, CODEOWNERS | QA |
| `docs` | Evidence and written documentation: `GATES.md`, `DECISIONS.md`, runbooks, `evidence/`, `specs/`, `submission/` | `GATES.md` is listed under PAY and QA, `DECISIONS.md` under QA; specs by area |
| `docsite` | This documentation website (Fumadocs on a Next.js static export) | not in the ownership map |
| `scripts` | Repository checks and smoke scripts | QA |
| `infra` | Environments, uptime and rollback notes | QA |
| `etc` | The committed API report of each package (`<package>.api.md`) | exempt from the ownership check |
| `reference` | An offline Python reference implementation (engine, fake PayPal, saga, parser) used by the differential and golden tests | not in the ownership map |
| `tools` | The `g4-receiver` helper for the webhook gate | not in the ownership map |

The ownership map is `scripts/ownership.map.json`. A pull request that touches more than one area needs the `cross-area` label (see [Contributing](/docs/builders/contributing)).

## Evidence in the repository

Committed evidence lives under `docs/evidence`: `G1`, `G2`, `G4` (<Term id="gate">gate</Term> runs as redacted JSONL), `nightly` (redacted nightly sandbox reports) and `SIM` (the <Term id="simulated">simulated</Term> multi-day run). `docs/GATES.md` is the record that ties each gate to its result; this site reads its gate and simulation tables from that file and from `docs/evidence/SIM/SIM-MULTIDAY.md` at build time.
