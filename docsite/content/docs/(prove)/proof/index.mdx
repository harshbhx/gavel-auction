| Grade | Example |
| --- | --- |

| Real sandbox, run log only | Gate G0, and the raw nightly job logs (they expire with Actions retention) |
| Fake PayPal | Whole-auction settlement and crash recovery |
| Simulated | The 30 day run, on a model of PayPal with a fake clock |
