Status: **published on Hugging Face.** The five datasets, the Evidence Explorer Space and the collection are live: [the collection](https://huggingface.co/collections/harshbhx/gavel-evidence-auction-holds-hammer-and-receipts-6af0afebebb37eb4c9184504) groups them.

Five small datasets are built in CI from evidence that is committed in this repository. Each one is labelled for what it is, ships a `MANIFEST.json` with a sha256 for every file and the commit it was built from, and a `verify.py` that recomputes the hashes. A privacy and secret scan runs on every output.

Nothing here is production data, no real person or real money is involved, and the sandbox numbers say nothing about production PayPal. The full description of each dataset, and how they are built and published, is in `docs/HF_COLLECTION.md`. See also [Real, simulated, recorded](/docs/judges/real-vs-simulated).

### What is checked

| Area | Check |
| --- | --- |
| Schema | Every table has a schema (types, nulls, ranges, enums, key); wrong or missing fields fail the build |
| Money | Integer cents, never negative |
| Ledger | Held equals captured plus released plus open, per lot and per hold, in the simulated run |
| Time | Timestamps and sequence numbers never go backwards; percentiles are ordered |
| Consistency | Scores recompute from outputs; evidence hashes equal the ones in `docs/GATES.md`; counts add up |
| Privacy | No emails, tokens, key-like strings, IPs or payment-object-like ids; demo actors anonymised |

### Reproducible and verifiable

- One command, `scripts/hf/build.sh`, runs the chain. The workflow runs it twice and fails if the two `MANIFEST.json` files differ.
- Every dataset carries `MANIFEST.json` (version, repository commit, build run URL, sha256 and row count of every file, source files) and `verify.py`, which recomputes the hashes.
- Every dataset has a version and a `CHANGELOG.md`; the data dictionary and a data-quality report are generated in CI and are in the run artifact.

### Honest labels

Real <Term id="sandbox">sandbox</Term> (PayPal sandbox, small samples, never production), simulated (fake clock, a model of PayPal), test voice clips (machine-generated speech), test PayPal (scripted demo auctions). The pipeline shows the data is well formed and traceable; it does not turn a simulation into a measurement. The full write-up is `docs/DATA-ENGINEERING.md` in the repository.
