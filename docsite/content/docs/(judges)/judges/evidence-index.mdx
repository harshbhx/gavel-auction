## Gate G5 numbers (24 clips each, synthetic and noise-free)

<SpeechTable />

The limit is a wrong-accept rate of 0.05 or less. Every row is within it, but the first run (Deepgram nova-2, Groq without a prompt) was above it at 0.083 to 0.167, and the fixes were chosen on these same clips, so the gate is not marked passed. The recorded provider outputs are in [`packages/voice/fixtures/stt-cache`](https://github.com/harshbhx/gavel-auction/tree/main/packages/voice/fixtures/stt-cache) and [`stt-cache-human`](https://github.com/harshbhx/gavel-auction/tree/main/packages/voice/fixtures/stt-cache-human); the clips are under [`packages/voice/fixtures/audio`](https://github.com/harshbhx/gavel-auction/tree/main/packages/voice/fixtures/audio). The human-like set was first recorded by voice-eval run 42342379648; the current recordings come from the option trials of VOI-02. With 24 clips, one clip moves a rate by 0.042, so differences between the two sets are within noise.
