## How to read a status

| Word | Meaning here |
| --- | --- |
| PASS | A real PayPal sandbox run with committed evidence or a named run log. |
| FAIL | Measured and below the limit. The fallback is in place. |
| IN PROGRESS | A real run that has started and has no final result yet. |
| SIMULATED | Our code over a model of PayPal on a fake clock. It says nothing about PayPal itself. |

When a page here and `docs/GATES.md` disagree, the gate record wins. The gate table above is generated from it when the site is built.
