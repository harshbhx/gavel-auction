## The four words

| Word | Meaning | Example |
| --- | --- | --- |
| Real | A call to the PayPal sandbox with committed evidence or a run log | G1, G2, G4 |
| Fake | The built-in fake PayPal, a test double | Whole-auction settlement tests |
| Simulated | Our code over simulated days on a fake clock against a model of PayPal | The 30-day run |
| Recorded | A replay of recorded events or cached speech outputs | The voice replay, G5 |
