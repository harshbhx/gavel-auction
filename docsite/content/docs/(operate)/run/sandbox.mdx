<Chip kind="sandbox">Sandbox</Chip>

Set `PAYMENTS=sandbox` and provide `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET` and `PAYPAL_WEBHOOK_ID`. The names are in `.env.example`; keep the values in your local `.env` and never commit them.

```bash
# names only: values live in your .env, never in the repository
PAYMENTS=sandbox
PAYPAL_ENV=sandbox
PAYPAL_CLIENT_ID=
PAYPAL_CLIENT_SECRET=
PAYPAL_WEBHOOK_ID=
```

<Term id="sandbox">Sandbox</Term> buyer accounts are created in the PayPal developer dashboard. Credentials are never stored in this repository; organisers hand out a test buyer at the event. Never use a real account.

<Held title="Timing">

PayPal's <Term id="honor-period">honor period</Term> for an <Term id="authorization">authorization</Term> is unproven (gate <Term id="gate-g3">G3</Term>). Register, bid and <Term id="hammer">hammer</Term> within one sitting.

</Held>

The gate runbook shows how each sandbox run is recorded: see [re-running a gate](/docs/run/gate-runbook).
