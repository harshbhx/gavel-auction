Four words are used with care on this site.

| Word | Meaning |
| --- | --- |
| Real | A call to the PayPal <Term id="sandbox">sandbox</Term>, with committed evidence or a run log. |
| Fake | The project's built-in <Term id="fake-paypal">fake PayPal</Term>, a test double. Behaviour there says nothing about PayPal. |
| <Term id="simulated">Simulated</Term> | The code run over simulated days with a fake clock against a model of PayPal. |
| Recorded | A replay of recorded events or cached speech outputs. |

## By area

| Area | Status | Basis |
| --- | --- | --- |
| Auction rules, price, soft close, hammer | Real code | Deterministic <Term id="engine">engine</Term>, the same in every mode. Covered by unit, property and fixture tests. |
| Hold creation (AUTHORIZE) | Real on the sandbox | <Term id="gate">Gate</Term> <Term id="gate-g2">G2</Term> PASS: wallet buyer and guest card authorized with the PayPal JS SDK v6. |
| Partial capture with `final_capture` | Real on the sandbox | Gate G1 PASS for two PayPal-account buyers. Guest card capture is the next addition. |
| Remainder release | Inferred | The authorization reads CAPTURED and a void answers 422 PREVIOUSLY_CAPTURED. Reading a buyer balance is the next step. |
| Webhook signature verification | Real on the sandbox | Gate <Term id="gate-g4">G4</Term> PASS: six real deliveries verified. Rejecting a tampered event is covered against the fake PayPal; a sandbox run of it is next. |
| Whole-auction settlement | Fake, plus sandbox lots | Settlement <Term id="saga">saga</Term> against the fake PayPal. On the real sandbox, nightly specs R7 and R8 settled one lot of three holds (runs 42200708552 and 42317068784, redacted reports committed) and 20 settlements of 6 holds were measured end to end (run 42346811713). Driving a whole auction through a server is the next step. |
| Crash recovery | Fake, plus one sandbox crash | Injected crashes against the fake PayPal. Spec R10 recovered from one in-process crash on the sandbox. A real server process was killed once on a CI runner against the sandbox and recovered with one capture (run 42558021614); the deployed host is not yet killed. |
| Honor period and reauthorize | Timed probe running | Gate G3 is a real sandbox probe: day 0 recorded 7 Nov 03:06 UTC, final reading about 12 Nov 06:17 UTC. The 30 day run is simulated. |
| Voice | Recorded | Cached transcripts by default. Live speech only with `VOICE_STT` set. Gate <Term id="gate-g5">G5</Term> PARTIAL: measured on synthetic audio, live-room confirmation is the next step; bids always confirm. |
| Hosted demo | Hosted in sandbox mode | Web at gavel.dualmindlab.tech, API at api.gavel.dualmindlab.tech, persistent disk. A recorded walk of the flow is the next step. |
