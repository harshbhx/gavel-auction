<Held title="What changes the decision">

If G3 shows a window shorter than the longest planned auction, auctions are capped to it, or the decision moves to NO-GO for long auctions. If G3 passes with a window that covers the planned auctions, the decision becomes GO for card and wallet. Speech stays behind the <Term id="confirm-prompt">confirm prompt</Term> either way.
