Nothing here is hidden elsewhere. Each item points to the page with the detail.

- **No hosted demo.** No URL is published. The runnable path is a local run on the fake PayPal. ([demo guide](/docs/start/demo))
- **Whole-auction settlement and crash recovery are fake-PayPal results.** The sandbox gates cover single calls and the nightly specs. No real server kill has run on a hosted host. ([crash recovery](/docs/how-it-works/crash-recovery))
- **The 30 day run is simulated.** It shows the code is consistent with a model of PayPal, not that PayPal behaves like the model. ([simulation](/docs/proof/simulation))
- **G3 is not finished.** The honor period and validity window are unknown until the probe ends. A hold older than 2 hours is flagged stale; it is still captured.
- **The remainder release is inferred.** No buyer balance was read; guest card capture was not run. ([gates](/docs/proof/gates))
- **Voice is behind a confirm prompt.** G5 failed on synthetic audio; there is no real-room test and no live speech run. The web console has no audio sender yet. ([voice](/docs/how-it-works/voice-and-confirm))
- **Latency is not within budget.** The void p95 of 1235.96 ms (n=10) is above the 1 s per-call budget behind the 6 s SETTLED target. ([latency](/docs/proof/latency))
- **Rejected bids are not in the ledger.** They are kept in the room log only, so the ledger cannot prove them. ([engine and ledger](/docs/how-it-works/engine-and-ledger))
- **Security review is unsigned.** All 18 items are open. ([security review](/docs/safety/security-review))
- **Accessibility manual pass not done.** ([accessibility](/docs/proof/accessibility))
- **Card and guest checkout in a live room.** G2 proves the SDK authorize flow only; no live-room checkout run is recorded.
