## Endpoints

| Area | Method and path | Credential |
| --- | --- | --- |
| Auctions | `POST /api/auctions` | operator key |
| Auctions | `GET /api/auctions/{id}` (id or join code) | none |
| Auctions | `POST /api/auctions/{id}/auctioneer/rotate`, `revoke-all`, `revoke` | operator key |
| Control | `POST /api/auctions/{id}/control`, `POST /api/auctions/{id}/kill` | auctioneer token |
| Bidding access | `POST /api/auctions/{id}/invites`, `POST /api/auctions/{id}/bidders/{bidderId}/invite` | auctioneer token |
| Bidding access | `POST /api/auctions/{id}/join` | invite token in the body |
| Read | `GET /api/auctions/{id}/snapshot` | auctioneer, screen, session or reviewer token |
| Read | `GET /api/auctions/{id}/events` | auctioneer, screen or reviewer token |
| Holds | `POST /api/holds`, `POST /api/holds/{holdId}/approve`, `GET` and `DELETE /api/holds/{holdId}` | session token |
| Judge rooms | `GET /api/judge/capabilities`, `POST /api/judge/rooms`, `POST /api/judge/join` | none (create also accepts the judge key) |
| Judge rooms | `POST /api/judge/key` | judge key |
| Judge rooms | `GET /api/judge/rooms/{id}/ledger` | reviewer or auctioneer token |
| Judge rooms | `POST /api/judge/rooms/{id}/sim-hold` | session token |
| Judge rooms | `POST /api/judge/pause` | operator key |
| Receipts | `POST /api/auctions/{id}/receipt-link` | session token |
| Receipts | `GET /api/auctions/{id}/receipt` | receipt token |
| Export | `GET /api/auctions/{id}/export` (NDJSON) | auctioneer token or operator key |
| Health | `GET /healthz`, `/readyz`, `/version`, `/warmup` | none |
| Operator | `/admin/export`, `/admin/replay-bundle`, `/metrics`, `/metrics/prometheus`, `/ops/summary`, `/ops/rooms`, `/ops/auctions/{id}/void-all`, `release-review` | operator key |

The PayPal webhook and the three demo routes are left out on purpose: PayPal alone calls the webhook, and the demo routes exist only when the host runs in demo mode, never in production.

## Authentication

| Credential | Sent as | Lifetime |
| --- | --- | --- |
| Operator key | header `X-Admin-Key` | set by the host operator |
| Auctioneer token | `Authorization: Bearer` | 12 hours |
| Screen token | `Authorization: Bearer` | 12 hours |
| Session token | `Authorization: Bearer` | 4 hours |
| Receipt token | `Authorization: Bearer` | 4 hours |
| Reviewer token | `Authorization: Bearer` | 12 hours, read only, from judge-room creation |
| Judge key | header `X-Judge-Key` | set by the host operator, optional, limited (never the operator key) |
| Invite token | body field `invite` of the join route | 24 hours, single use |

A token is bound to one auction and one kind. A reviewer token reads the snapshot, event log and room ledger of its own judge room and nothing else. The judge key only lifts the public judge-room limits and is sent only in its header. No real credential appears in the document.

## Errors

Every error is JSON with a `message`. Read the stable code as `code ?? error`: the core and judge routes send `code`, the hold, judge and operator routes send `error`, and `detail` is optional extra text.

```json
{ "code": "bad_message", "message": "invalid request body", "detail": "config.reserve: reserve must be at least 100 cents" }
```

Statuses in use: 400, 401, 403, 404, 409, 410, 413, 415, 429, 500 and 503. A 429 always carries `Retry-After`.

## Rate limits

Each operation that has its own limit carries an `x-rate-limit` extension, and the host-wide defaults sit under `x-rate-limits`. By default a source address gets 60 write requests a minute (reads have their own 300 a minute bucket) on every route except health and webhooks, 10 joins a minute, and 12 judge rooms an hour.

## WebSocket protocol

Live bidding runs on `wss://<host>/ws`. OpenAPI cannot describe a socket, so the document carries a prose section and this site has the full contract on [WebSocket protocol](/docs/reference/websocket-protocol). In AsyncAPI terms the channel `/ws` has three client messages (`join`, `bid`, `confirm_response`) and ten server messages (`registered`, `state`, `price`, `bid_accepted`, `bid_rejected`, `confirm_request`, `hammer`, `settlement_update`, `audit_event`, `error`).

## SDKs with APIMatic

GAVEL is entered for the sponsor prize "Best Use of APIMatic". The SDKs are generated by APIMatic from the OpenAPI document above and published as a GitHub Release. They are beta, sandbox only, and not on npm, PyPI or NuGet.

<Callout type="info" title="gavel-sdk 0.0.5 (beta)">
  Release: [https://github.com/harshbhx/gavel-auction/releases/tag/sdk-v0.0.5](https://github.com/harshbhx/gavel-auction/releases/tag/sdk-v0.0.5). Source: [sdks/](https://github.com/harshbhx/gavel-auction/tree/main/sdks).
</Callout>

| Language   | Package     | Source                                                                                  | Install from the release asset                  | Import                            |
| ---------- | ----------- | --------------------------------------------------------------------------------------- | ----------------------------------------------- | --------------------------------- |
| TypeScript | `gavel-sdk` | [sdks/typescript](https://github.com/harshbhx/gavel-auction/tree/main/sdks/typescript)  | `npm install ./gavel-sdk-0.0.5.tgz`             | `import { ... } from "gavel-sdk"` |
| Python     | `gavel-sdk` | [sdks/python](https://github.com/harshbhx/gavel-auction/tree/main/sdks/python)          | `pip install ./gavel_sdk-0.0.5-py3-none-any.whl` | `import gavel_host_api`           |
| C#         | `GavelSdk`  | [sdks/csharp](https://github.com/harshbhx/gavel-auction/tree/main/sdks/csharp)          | `dotnet add package GavelSdk --version 0.0.5 --source .` | `using GavelHostApi;`     |

Download the asset from the release page first, then run the install command in the folder that holds it (for C#, the folder is the package source). Each package folder has its own README, API reference and SDK map written by the generator.

The default server in the SDKs is the PayPal sandbox host. The bearer token kinds are separate security schemes (`auctioneerAuth`, `screenAuth`, `sessionAuth`, `receiptAuth`) and the operator key is `adminKey`.

<Callout type="warn" title="Not published yet">
  The APIMatic developer portal (reference docs, code samples, try-it) is generated but not hosted at a public address yet.
</Callout>

How the SDKs are made: import `openapi/gavel.yaml` in APIMatic (from the raw file URL `https://raw.githubusercontent.com/harshbhx/gavel-auction/main/openapi/gavel.yaml` or by upload), fix what the validation report names, generate, then patch the package name and version. A tag `sdk-v<version>` builds both packages in GitHub Actions and creates the release.

The WebSocket is outside what an OpenAPI-based SDK generates, so live bidding stays on the documented socket protocol.
