## Effects

A transition can return effects that the runner executes after it saves the <Term id="journal">journal</Term>: `capture` (cursor, bidder, hold, authorization id, amount), `void_holds` (every hold except the winner's, sorted by id) and `flag_review` (with a reason).

## Crash boundaries

The runner reports a boundary at every save (`journaled:<event>`) and around each PayPal call: `before:capture`, `after:capture`, `before:get`, `after:get`, `after:void`. The simulation and the `GAVEL_CHECKPOINT_KILL` test hook use these labels.
