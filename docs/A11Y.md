# Accessibility pass

Spec: R-QA-037 (docs/specs/quality/SPEC-quality.md). This file records the manual pass that
complements the scripted checks. Nothing below is marked as passed until a person has run it
and filled in the date and tester.

## Scripted coverage (runs in CI)

- axe-core in Playwright on every view and state listed in section 4.10 of the quality spec,
  zero serious or critical violations.
- `packages/web/test/component/a11y.test.tsx`: one h1, named buttons and links, labelled form
  controls, unique ids, decorative svg hidden, text alternatives for images.
- `packages/web/test/unit/announcer.test.tsx`: live region announcements.

## Views

Bidder (register, bidding, outbid, won, lost), auctioneer console, public projected view,
audit view, quality page.

## Checks per view

1. Every control is reachable by Tab in a logical order and has a visible focus ring.
2. The screen reader announces the control name, role and state.
3. A price change is announced once through the live region, not repeated on every update.
4. Outbid, won and error states are announced without moving focus.
5. At 200 percent zoom there is no horizontal scrolling and no clipped or overlapping text.
6. Text contrast is at least 4.5:1 (3:1 for large text and UI parts).
