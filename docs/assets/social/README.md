## GitHub social preview: owner action needed

GitHub lets only the repository owner set the social preview, in Settings > General > Social preview. It cannot be changed by a pull request, so the repository owner must upload `github-social-preview.png` by hand. Until then GitHub shows its generated card.

## YouTube end screen notes

YouTube requires the video to be at least 25 seconds long, and end screens run 5 to 20 seconds at the end, with up to four elements and at least one video or playlist. Public guides disagree on exact element pixel sizes (reports range from about 300x170 to 615x345 for video elements on a 1280x720 basis), and no official YouTube page was fetched, so confirm the final placement in the Studio end screen editor. The card leaves two 560x315 (16:9) video zones and a 300 px subscribe circle, with the rest left as plain paper.

## Honesty and accessibility

- The hook line is true: a bid is a PayPal authorization hold and the charge happens at the hammer. "Nobody pays until the hammer" means no bidder is charged before the hammer.
- Use the SIMULATED chip on scripted or fake-PayPal footage and RECORDED only on real sandbox footage.
- Text is 20 px or larger on 1200 px cards, orange is only used as a background behind ink text (orange text appears only on the dark thumbnail, where contrast is above 4.5:1).
