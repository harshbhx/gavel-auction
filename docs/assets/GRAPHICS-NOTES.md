# Graphics notes

> Curation (DOC-60): which of these animated files are used, and which were moved to `brand/archive/`, is listed in [`brand/CURATION.md`](../../brand/CURATION.md).

A running record of every animated graphic: what it is, where it comes from, how to re-render it, how big it is and where it is used. Updated in each graphics PR. Nothing here is rendered on a laptop or the VM: the `graphics` workflow does all rendering.

## Motion language

A confident ease, GAVEL's own (no gears, no cogs, no teeth, no stepped easing). The Mallet G draws round, the mallet winds up and strikes, a smooth round shockwave ring leaves the G, the G settles, then the wordmark glides in (under 3 seconds, then a 1 second hold). Other motifs come from the product: a simulated bid ladder ticking up, hash-chain links snapping together into a receipt, and the hold, hammer, receipt flow. The README graphics are minimal on purpose: one idea each, big type, whitespace, motion from the first frame, loops of 4 to 10 seconds, GIFs at 20 fps. Colours are the brand tokens (paper `#efe6d3`, ink `#1d1712`, signal orange `#ff6a1f`), fonts are the app fonts. Pages are sampled by seeking, so every render is deterministic.

Tone and honesty: the graphics lead with what is built and proven and keep limits to one small neutral label (PayPal sandbox only). Every number is true as recorded: live voice 24 of 24 synthetic clips answered with no bid accepted without a confirm (`docs/evidence/voice-live-socket`, run 42575018866), server kill 0 differences between journal and PayPal (`docs/evidence/server-kill`), 19-entry hash chain verifies. Anything simulated says so, no gate is shown as passed beyond `docs/GATES.md`, and the wording is held, not charged.

## How to re-render

1. Edit a source under `graphics/` (or `brand/svg`), push the branch.
2. Run the `graphics` workflow (it also runs on pull requests that touch `graphics/**` or `brand/svg/**`), or dispatch it: `gh workflow run graphics.yml --ref <branch>`.
3. Download the artifacts: `gh run download <run id> -n graphics-motion-readme -n graphics-motion-brand -n graphics-motion-ui`. Each artifact has a `report.txt` with sizes and frame counts.
4. Copy the files into the folders below and commit them. `motion-ui` cuts clips from the videos of a judge-smoke run (`UI_RUN`, default in `graphics/motion-ui/render.mjs`) and speeds up the waiting; to refresh the clips, run `judge-smoke` and set the new run id and clip times there.

Prettier runs on the sources and docs (`prettier --check .` in CI).

Art direction: a printed auction house broadside. Flat paper, black ink, one orange accent, huge tight type from the app fonts, hairline rules that draw themselves, lot numbers, type revealed through masks, numerals counting, the hammer strike as the hero, real app frames hard-cropped with no frame.
