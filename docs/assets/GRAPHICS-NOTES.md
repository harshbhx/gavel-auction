# Graphics notes

A running record of every animated graphic: what it is, where it comes from, how to re-render it, how big it is and where it is used. Updated in each graphics PR. Nothing here is rendered on a laptop or the VM: the `graphics` workflow does all rendering.

## Motion language

A confident ease, GAVEL's own (no gears, no teeth, no stepped easing). The Mallet G draws round, the mallet winds up and strikes, a smooth round shockwave ring leaves the G, the G settles, then the wordmark glides in. Other motifs come from the product: a simulated bid ladder ticking up, hash-chain links snapping together into a receipt, and the hold, hammer, receipt flow. Colours are the brand tokens (paper `#efe6d3`, ink `#1d1712`, signal orange `#ff6a1f`), fonts are the app fonts. Pages are sampled by seeking, so every render is deterministic.

Honesty rules for content: numbers come from `docs/GATES.md` and `docs/evidence/` and carry a measured, met or missed label; anything simulated says so; G3 is in progress, G5 is partial; the wording is "held, not charged".

## How to re-render

1. Edit a source under `graphics/` (or `brand/svg`), push the branch.
2. Run the `graphics` workflow (it also runs on pull requests that touch `graphics/**` or `brand/svg/**`), or dispatch it: `gh workflow run graphics.yml --ref <branch>`.
3. Download the artifacts: `gh run download <run id> -n graphics-motion-readme -n graphics-motion-brand -n graphics-motion-ui`. Each artifact has a `report.txt` with sizes and frame counts.
4. Copy the files into the folders below and commit them. `motion-ui` cuts clips from the videos of a judge-smoke run (`UI_RUN`, default in `graphics/motion-ui/render.mjs`); to refresh the clips, run `judge-smoke` and set the new run id there.

## Devpost set (GFX-10, auction broadside)

| Set              | Source                                                                                             | Artifact                  | Committed to           |
| ---------------- | -------------------------------------------------------------------------------------------------- | ------------------------- | ---------------------- |
| `motion-devpost` | `graphics/motion-devpost/` (`render.mjs`, `kit.mjs`, `runtime.js`, `slides-a.mjs`, `slides-b.mjs`) | `graphics-motion-devpost` | `docs/assets/devpost/` |

Art direction: a printed auction house broadside. Flat paper, black ink, one orange accent, huge tight type from the app fonts, hairline rules that draw themselves, lot numbers, type revealed through masks, numerals counting, the hammer strike as the hero, real app frames hard-cropped with no frame. No cards, chips, badges, gradients, glows or shadows, no window mockups. Each slide is a pure function of time (`runtime.js`) sampled by seeking, so a render is deterministic; it moves from frame 0, runs one sequence in about 3.5 s, then masks out and loops (5 s). GIFs are 20 fps (each under 4 MB, enforced in `render.mjs`), MP4 and WebM 24 fps, and a poster still. The artifact also holds `contact-*.png` frame sheets and `report.txt` (review only). Slide 04 uses `docs/assets/readme/see-it-run-*.png`. Partners are names in type, no logos. Labels kept: "PayPal sandbox only", real or simulated dataset labels, shortened example hashes. No latency numbers or gate verdicts. No gear, tooth or stepped shapes.

Re-render: push (the `graphics` workflow runs on `graphics/**`), `gh run download <run id> -n graphics-motion-devpost`, copy `0*.gif`, `0*.mp4`, `0*.webm`, `0*-poster.png` into `docs/assets/devpost/`.
