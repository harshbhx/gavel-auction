| `architecture-flow.gif`                                                                              | Animation of one bid through GAVEL in five numbered steps: the Cloudflare Worker serves the web app, the bidder's hold and bids go to the Render API, the API asks PayPal sandbox for the hold and checks each bid against it, at the hammer the winner is captured and the other holds are voided with every step in the ledger, and a receipt is issued that anyone can verify. |
| `lifecycle-light.svg`, `lifecycle-light.png`, `lifecycle-dark.svg`, `lifecycle-dark.png`             | The GAVEL lifecycle in five steps: hold (PayPal holds the bidder's ceiling before bidding), bid (each bid is checked against that hold), hammer (the highest valid bid wins and pays the winning bid), receipt (other holds are voided and the result is in the ledger), verify (anyone can check the hash chain from the export).                                                |
